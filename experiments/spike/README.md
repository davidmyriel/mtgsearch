# Spike (21 November 2026)

The throwaway scripts that tested the idea before this repository existed: 5,000 of the
most-played Commander cards, art crops for the top 1,489, and a query set frozen before
indexing. Kept for the record; nothing here is imported by the package.

Results (`results.json`): semantic search ranked the right card first for 11 of 15
descriptive queries and 12 of 12 art descriptions; Scryfall's own search returned none of the
15 for the plain-English query text.
